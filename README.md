# h3-comfy

ชุดติดตั้งและใช้งาน **MiniMax H3** (โมเดลเจนวิดีโอพร้อมเสียง) บน ComfyUI
พร้อมความรู้ที่ได้จากการใช้งานจริงว่าต้องเขียน prompt ยังไงมันถึงจะวาดตาม

เขียนสำหรับสองกลุ่ม: **คนที่ทำตามเอง** และ **AI agent ที่ช่วยคนทำ**

---

## นี่คืออะไร

H3 เจนคลิปวิดีโอที่มีทั้งภาพและเสียงพูดออกมาพร้อมกัน จากรูปตัวละครกับข้อความบรรยาย
แต่ของแบบนี้มีรายละเอียดยิบย่อยเยอะมากที่ถ้าไม่รู้จะเสียเวลา (และเสียเงินค่าเช่าเครื่อง) ไปเปล่าๆ
ชุดนี้รวบรวมสิ่งที่เรียนรู้มาแล้วไว้ให้

| ต้องการอะไร | ไปที่ |
|---|---|
| ไม่มีการ์ดจอแรง อยากเช่าเครื่องมาลอง | [คู่มือ 1 — เช่า vast.ai](guides/01-rent-vast.md) |
| ติดตั้งอยู่ ติดตรงรหัสโหลดโมเดล | [คู่มือ 2 — HF token](guides/02-hf-token.md) |
| พร้อมติดตั้งแล้ว | [คู่มือ 3 — ติดตั้ง](guides/03-install.md) |
| ติดตั้งเสร็จแล้ว อยากเขียน prompt | [skills/h3-prompt](skills/h3-prompt/SKILL.md) |
| อยากสั่งเจนหลายคลิปต่อกันเป็นเรื่อง | [skills/h3-run](skills/h3-run/SKILL.md) |

## ต้องมีอะไรบ้าง

| | ขั้นต่ำ | หมายเหตุ |
|---|---|---|
| **การ์ดจอ** | **NVIDIA RTX 50 ซีรีส์ · VRAM 16 GB** | **รุ่นอื่นใช้ไม่ได้** ดูข้างล่าง |
| พื้นที่ว่าง | 100 GB | ตัวโมเดล 38 GB ที่เหลือไว้เก็บคลิป |
| ComfyUI | ติดตั้งไว้แล้ว | เครื่องเช่าเลือกเทมเพลตที่มี ComfyUI ได้เลย |
| บัญชี Hugging Face | ฟรี | ใช้โหลดไฟล์โมเดล |

**ไม่มีการ์ดจอ?** เช่าได้ ราวชั่วโมงละ 20–40 บาท ดู [คู่มือ 1](guides/01-rent-vast.md)

### การ์ดที่รองรับ

ชุดนี้รองรับเฉพาะตระกูล **Blackwell** — จำง่ายๆ ว่า **เลขรุ่นขึ้นต้นด้วย 50**

| ใช้ได้ ✅ | ใช้ไม่ได้ ❌ |
|---|---|
| RTX 5060 Ti · 5070 · 5070 Ti · 5080 · 5090 | RTX 40 ซีรีส์ · 30 ซีรีส์ |
| RTX PRO 6000 Blackwell · B200 | A100 · H100 · L40S · A6000 |

**เป็นการจำกัดขอบเขตโดยตั้งใจ ไม่ใช่ข้อจำกัดทางเทคนิค** ตัวเลขทุกตัวในเอกสารชุดนี้
วัดมาจากการ์ดตระกูลนี้ จึงรับประกันเฉพาะตระกูลนี้ การ์ดรุ่นเก่ากว่ารันโมเดลนี้ได้เหมือนกัน
แต่เราไม่มีตัวเลขที่วัดเองยืนยัน — อยากลองเองใช้ `FORCE=1` ได้ แต่ไม่มีอะไรรับประกัน

`check_stack.py` ตรวจให้ตั้งแต่**ก่อนโหลดไฟล์ 38 GB** เผลอเช่าผิดรุ่นจึงเสียแค่ค่าเช่าไม่กี่นาที

## เริ่มเร็ว (สำหรับคนที่มีเครื่องพร้อมแล้ว)

```bash

git clone https://github.com/capruokz/h3-comfy && cd h3-comfy/skills/h3-setup/scripts
bash setup.sh
python3 find_ceiling.py
```

## ใช้กับ AI agent

โฟลเดอร์ `skills/` เป็นรูปแบบ Agent Skill มาตรฐาน แต่ละอันมี `SKILL.md` ที่บอกว่า
ใช้เมื่อไหร่และทำยังไง

**Claude Code / Claude Desktop** — ก๊อปโฟลเดอร์ใน `skills/` ไปวางที่ `~/.claude/skills/`
หรือติดตั้งทั้งรีโปเป็นปลั๊กอิน

**agent อื่น** — ตรรกะจริงอยู่ในสคริปต์ ไม่ได้อยู่ในคำบรรยาย อะไรก็ตามที่อ่านไฟล์
และรันคำสั่งได้ก็ใช้ชุดนี้ได้ ให้มันอ่าน `SKILL.md` ของสกิลที่เกี่ยวข้องแล้วรันสคริปต์ตามนั้น

---

## เรื่องที่ต้องรู้ก่อนเชื่อตัวเลขในเอกสารนี้

**ตัวเลขความเร็วและความยาวคลิปสูงสุดในเอกสาร วัดมาจากการ์ด 16 GB ใบหนึ่ง**
ไม่ใช่ความจริงของทุกใบ ตรงไหนที่มีตัวเลขแบบนั้น จะเขียนกำกับไว้ว่าวัดจากอะไร

ให้รัน `find_ceiling.py` เพื่อหาตัวเลขของเครื่องคุณเอง แล้วใช้ตัวเลขนั้นแทน —
นี่คือเหตุผลที่มีสคริปต์ตัวนั้นอยู่

---

## ความปลอดภัย

- **ไม่มี token หรือรหัสอะไรอยู่ในชุดนี้** ทุกสคริปต์อ่านจากตัวแปรระบบ `HF_TOKEN` เท่านั้น
- **อย่าใส่ token ลงในไฟล์ใดๆ ในรีโปนี้** ถ้าจะแก้แล้ว push ขึ้น git ให้เช็คก่อนเสมอ
- ถ้าเผลอทำ token หลุด ให้ไปกดลบที่ https://huggingface.co/settings/tokens ทันที
  แล้วสร้างใหม่ ใช้เวลาไม่ถึงนาที

---

## ไม่ได้แจกอะไร

- **ไม่มีไฟล์โมเดล** ชุดนี้มีแค่รายชื่อกับสคริปต์โหลด ตัวไฟล์โหลดจากต้นทางเอง
- **ไม่มีรูปตัวละครหรือไฟล์เสียงตัวอย่าง** ต้องเตรียมเอง
  ดู [skills/h3-prompt](skills/h3-prompt/SKILL.md) ว่ารูปอ้างอิงควรเป็นแบบไหน

> **ระวังเรื่องไฟล์เสียงอ้างอิง** ถ้าเอาไฟล์เสียงที่มีคนพูดอยู่มาใช้เป็นตัวอ้างอิงเสียง
> H3 มีโอกาสพูดคำที่อยู่ในไฟล์นั้นออกมาแทนบทที่คุณเขียน ใช้ไฟล์สั้นๆ และคลิปไหน
> ไม่มีบทพูดก็อย่าต่อไฟล์เสียงเข้าไปเลย
