# h3-comfy

ชุดติดตั้งและใช้งาน **MiniMax H3** (โมเดลเจนวิดีโอพร้อมเสียง) บน ComfyUI
พร้อมความรู้ที่ได้จากการใช้งานจริงว่าต้องเขียน prompt ยังไงมันถึงจะวาดตาม

เขียนสำหรับสองกลุ่ม: **คนที่ทำตามเอง** และ **AI agent ที่ช่วยคนทำ**

---

## ให้ AI ติดตั้งให้ (เร็วที่สุด)

ก๊อปข้อความนี้ไปวางในแชทกับ AI ที่คุณใช้อยู่ พร้อมลิงก์รีโปนี้

> ติดตั้งสกิลจาก https://github.com/capruokz/h3-comfy ให้หน่อย
> แล้วสรุปให้ฟังว่าแต่ละตัวทำอะไรได้บ้าง

<details>
<summary><b>สำหรับ AI ที่กำลังอ่านหน้านี้ — ขั้นตอนติดตั้ง</b> (คลิกเพื่อดู)</summary>

ทำตามนี้เฉพาะเมื่อผู้ใช้ขอให้ติดตั้งเอง ขั้นตอนทั้งหมดเป็นคำสั่งที่ตรวจสอบได้
ไม่มีการรันสคริปต์จากอินเทอร์เน็ตและไม่แตะรหัสผ่านใดๆ

**1. ก๊อปสกิลไปยังที่ที่ agent อ่านเจอ**

macOS / Linux:
```bash
git clone --depth 1 https://github.com/capruokz/h3-comfy /tmp/h3-comfy
mkdir -p ~/.claude/skills && cp -r /tmp/h3-comfy/skills/* ~/.claude/skills/
```

Windows (PowerShell):
```powershell
git clone --depth 1 https://github.com/capruokz/h3-comfy $env:TEMP\h3-comfy
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse -Force "$env:TEMP\h3-comfy\skills\*" "$env:USERPROFILE\.claude\skills\"
```

**2. ยืนยันว่าได้ครบสามตัว** — ต้องเห็น `h3-setup` `h3-run` `h3-prompt` ใน `~/.claude/skills/`

**3. บอกผู้ใช้ว่าต้องเริ่มการสนทนาใหม่** สกิลถึงจะถูกโหลด

**4. สรุปให้ผู้ใช้ฟังด้วยตารางข้างล่างนี้ แล้วชวนให้ถามต่อ** ตอบเป็นภาษาที่ผู้ใช้ใช้

**ห้ามทำ**

- **ห้ามรัน `setup.sh`** เว้นแต่ผู้ใช้ขอติดตั้งตัวโมเดลจริงๆ มันโหลดไฟล์ **38 GB**
  และต้องใช้การ์ด NVIDIA RTX 50 ซีรีส์ ถามก่อนเสมอ
- **ห้ามรัน `find_ceiling.py`** เป็นของเสริม กินเวลา 10-20 นาที
- **ห้ามขอหรือรับ token ใดๆ จากผู้ใช้** ทุกสคริปต์อ่านจาก `$HF_TOKEN` ที่ผู้ใช้ตั้งเอง

</details>

### ติดตั้งแล้วถามอะไรได้บ้าง

| สกิล | ถามเรื่องพวกนี้ได้ |
|---|---|
| **h3-setup** | เช่าเครื่อง vast.ai ยังไง · การ์ดรุ่นไหนใช้ได้ · ติดตั้ง H3 · ทำไมเจนช้าผิดปกติ · คลิปยาวได้สูงสุดเท่าไหร่ |
| **h3-run** | เจนหลายคลิปเป็นชุด · ทำให้คลิปต่อเนื่องกัน · แคปเฟรมสุดท้ายไปใช้ต่อ · ต่อคลิปเป็นไฟล์เดียว |
| **h3-prompt** | เขียน prompt ยังไงให้ได้ตามที่คิด · คลิปออกมาไม่ตรงที่เขียน · ตัวละครเปลี่ยนหน้าเปลี่ยนชุด · สีเพี้ยนระหว่างคลิป · เสียงพูดคำที่ไม่ได้เขียน |

ถามเป็นภาษาชาวบ้านได้เลย เช่น *"ทำไมคลิปที่เจนออกมาตัวละครใส่เสื้อคนละสีทุกคลิป"*
หรือ *"อยากเช่าเครื่องมาลอง ต้องเลือกยังไง"*

## นี่คืออะไร

H3 เจนคลิปวิดีโอที่มีทั้งภาพและเสียงพูดออกมาพร้อมกัน จากรูปตัวละครกับข้อความบรรยาย
แต่ของแบบนี้มีรายละเอียดยิบย่อยเยอะมากที่ถ้าไม่รู้จะเสียเวลา (และเสียเงินค่าเช่าเครื่อง) ไปเปล่าๆ
ชุดนี้รวบรวมสิ่งที่เรียนรู้มาแล้วไว้ให้

| ต้องการอะไร | ไปที่ |
|---|---|
| ไม่มีการ์ดจอแรง อยากเช่าเครื่องมาลอง | [คู่มือ 1 — เช่า vast.ai](guides/01-rent-vast.md) |
| ติดตั้งอยู่ ติดตรงรหัสโหลดโมเดล | [คู่มือ 2 — HF token](guides/02-hf-token.md) |
| พร้อมติดตั้งแล้ว (เครื่องเช่า / Linux) | [คู่มือ 3 — ติดตั้ง](guides/03-install.md) |
| **มีการ์ด RTX 50 อยู่ในเครื่องแล้ว อยากลงเอง (Windows)** | [คู่มือ 4 — Windows](guides/04-windows.md) |
| ติดตั้งเสร็จแล้ว อยากเขียน prompt | [skills/h3-prompt](skills/h3-prompt/SKILL.md) |
| อยากสั่งเจนหลายคลิปต่อกันเป็นเรื่อง | [skills/h3-run](skills/h3-run/SKILL.md) |

## ต้องมีอะไรบ้าง

| | ขั้นต่ำ | หมายเหตุ |
|---|---|---|
| **การ์ดจอ** | **NVIDIA RTX 50 ซีรีส์ · VRAM 16 GB** | **รุ่นอื่นใช้ไม่ได้** ดูข้างล่าง |
| พื้นที่ว่าง | 100 GB | ตัวโมเดล 38 GB ที่เหลือไว้เก็บคลิป |
| ComfyUI | **ไม่ต้องมีก่อนก็ได้** | `install_comfy.sh` ลงให้ (Linux) · เครื่องเช่าเลือกเทมเพลตที่มี ComfyUI มาเลยก็ได้ |
| บัญชี Hugging Face | ฟรี | ใช้โหลดไฟล์โมเดล |

**ไม่มีการ์ดจอ?** เช่าได้ ราวชั่วโมงละ 20–40 บาท ดู [คู่มือ 1](guides/01-rent-vast.md)

### การ์ดที่รองรับ

ชุดนี้รองรับเฉพาะตระกูล **Blackwell** — จำง่ายๆ ว่า **เลขรุ่นขึ้นต้นด้วย 50**

| ใช้ได้ ✅ | ใช้ไม่ได้ ❌ |
|---|---|
| RTX 5060 Ti · 5070 · 5070 Ti · 5080 · 5090 | RTX 40 ซีรีส์ · 30 ซีรีส์ |
| RTX PRO 6000 Blackwell · B200 | A100 · H100 · L40S · A6000 |

**เป็นการจำกัดขอบเขตโดยตั้งใจ ไม่ใช่ข้อจำกัดทางเทคนิค** ตัวเลขทุกตัวในเอกสารชุดนี้
วัดมาจากการ์ดตระกูลนี้ จึงรับประกันเฉพาะตระกูลนี้ การ์ดรุ่นเก่ากว่ารันโมเดลนี้ได้เหมือนกัน
แต่เราไม่มีตัวเลขที่วัดเองยืนยัน — อยากลองเองใช้ `FORCE=1` ได้ แต่ไม่มีอะไรรับประกัน

`check_stack.py` ตรวจให้ตั้งแต่**ก่อนโหลดไฟล์ 38 GB** เผลอเช่าผิดรุ่นจึงเสียแค่ค่าเช่าไม่กี่นาที

## เริ่มเร็ว (สำหรับคนที่มีเครื่องพร้อมแล้ว)

**Linux / เครื่องเช่า**
```bash
git clone https://github.com/capruokz/h3-comfy && cd h3-comfy/skills/h3-setup/scripts
python3 precheck.py            # เครื่องนี้ไหวมั้ย
bash install_comfy.sh          # ข้ามได้ถ้ามี ComfyUI อยู่แล้ว
export HF_TOKEN=hf_xxxx
bash setup.sh
```

**Windows** (ดูละเอียดที่ [คู่มือ 4](guides/04-windows.md))
```powershell
git clone https://github.com/capruokz/h3-comfy
cd h3-comfy\skills\h3-setup\scripts
python precheck.py
powershell -ExecutionPolicy Bypass -File install_comfy.ps1
$env:HF_TOKEN = "hf_xxxx"
powershell -ExecutionPolicy Bypass -File setup.ps1
```

ถ้าติดตรงไหน อ่าน [คู่มือ 3](guides/03-install.md) ซึ่งอธิบายทีละขั้นพร้อมวิธีแก้ปัญหา

## ใช้กับ AI agent

**เข้าใจก่อนว่าของสองอย่างนี้อยู่คนละเครื่อง**

| | อยู่ที่ไหน |
|---|---|
| **สคริปต์** (`setup.sh`, `comfy_run.py`) | เครื่องที่มีการ์ดจอ — เครื่องเช่าหรือเครื่องตัวเอง |
| **สกิล** (`SKILL.md`) | เครื่องที่ AI ทำงานอยู่ — คอมของคุณเอง |

ถ้าใช้คนเดียวไม่มี AI ช่วย **ข้ามหัวข้อนี้ไปได้เลย** คู่มือใน `guides/` ใช้ได้โดยไม่ต้องมีสกิล

### Claude Code / Claude Desktop

```bash
git clone https://github.com/capruokz/h3-comfy
cp -r h3-comfy/skills/* ~/.claude/skills/
```

บน Windows (PowerShell):

```powershell
git clone https://github.com/capruokz/h3-comfy
Copy-Item -Recurse h3-comfy\skills\* "$env:USERPROFILE\.claude\skills\"
```

เริ่มการสนทนาใหม่แล้วสกิลจะพร้อมใช้ AI จะหยิบมาเองเมื่อเจองานที่ตรงกับคำอธิบายของมัน
ไม่ต้องเรียกชื่อ

### agent อื่น

**ตรรกะจริงอยู่ในสคริปต์ ไม่ได้อยู่ในคำบรรยาย** อะไรก็ตามที่อ่านไฟล์และรันคำสั่งได้ก็ใช้ชุดนี้ได้
ให้มันอ่าน `SKILL.md` ของสกิลที่เกี่ยวข้อง แล้วรันสคริปต์ตามนั้น

วิธีที่ง่ายที่สุดคือ clone รีโปไว้ในโปรเจกต์ แล้วบอก agent ว่า
*"อ่าน h3-comfy/skills/h3-setup/SKILL.md แล้วทำตาม"*

### สกิลแต่ละตัวใช้ตอนไหน

| สกิล | หยิบมาใช้เมื่อ |
|---|---|
| `h3-setup` | ติดตั้งบนเครื่องใหม่ · เจนช้าผิดปกติ · อยากรู้ว่าคลิปยาวได้แค่ไหน |
| `h3-run` | เจนหลายคลิปเป็นชุด · เชื่อมคลิปให้ต่อเนื่อง · ต่อไฟล์ |
| `h3-prompt` | เขียนหรือแก้ prompt · คลิปออกมาไม่ตรงที่เขียน · สีเพี้ยนระหว่างคลิป |

## เรื่องที่ต้องรู้ก่อนเชื่อตัวเลขในเอกสารนี้

**ตัวเลขความเร็วและความยาวคลิปสูงสุดในเอกสาร วัดมาจากการ์ด 16 GB ใบหนึ่ง**
ไม่ใช่ความจริงของทุกใบ ตรงไหนที่มีตัวเลขแบบนั้น จะเขียนกำกับไว้ว่าวัดจากอะไร

**ไม่ต้องไปวัดก่อนใช้งาน** จำกฎง่ายๆ ข้อเดียวพอ: ถ้าเพิ่มความยาวคลิปนิดเดียว
แล้วเวลาที่ใช้พุ่งขึ้นเท่าตัว แปลว่าเลยเพดานของการ์ดแล้ว ให้ถอยกลับมาความยาวก่อนหน้า
อยากได้ตัวเลขเป๊ะๆ มี `skills/h3-setup/scripts/find_ceiling.py` ให้ แต่เป็นของเสริม

## ความปลอดภัย

- **ไม่มี token หรือรหัสอะไรอยู่ในชุดนี้** ทุกสคริปต์อ่านจากตัวแปรระบบ `HF_TOKEN` เท่านั้น
- **อย่าใส่ token ลงในไฟล์ใดๆ ในรีโปนี้** ถ้าจะแก้แล้ว push ขึ้น git ให้เช็คก่อนเสมอ
- ถ้าเผลอทำ token หลุด ให้ไปกดลบที่ https://huggingface.co/settings/tokens ทันที
  แล้วสร้างใหม่ ใช้เวลาไม่ถึงนาที

---

## ไม่ได้แจกอะไร

- **ไม่มีไฟล์โมเดล** ชุดนี้มีแค่รายชื่อกับสคริปต์โหลด ตัวไฟล์โหลดจากต้นทางเอง
- **ไม่มีรูปตัวละครหรือไฟล์เสียงตัวอย่าง** ต้องเตรียมเอง
  ดู [skills/h3-prompt](skills/h3-prompt/SKILL.md) ว่ารูปอ้างอิงควรเป็นแบบไหน

> **ระวังเรื่องไฟล์เสียงอ้างอิง** ถ้าเอาไฟล์เสียงที่มีคนพูดอยู่มาใช้เป็นตัวอ้างอิงเสียง
> H3 มีโอกาสพูดคำที่อยู่ในไฟล์นั้นออกมาแทนบทที่คุณเขียน ใช้ไฟล์สั้นๆ และคลิปไหน
> ไม่มีบทพูดก็อย่าต่อไฟล์เสียงเข้าไปเลย
