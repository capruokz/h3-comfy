ทุกตัวเลขในนี้วัดจากงานจริง ไม่ได้ประมาณ

## <a id="refs"></a>Reference: การแข่งกันด้วย token

`MiniMaxH3ReferenceToVideo` มีช่อง reference สี่ช่อง ไม่ใช่สอง

| ช่อง | ชนิด | สูงสุด | tag ในพรอมป์ต |
|---|---|---|---|
| `ref_images` | IMAGE | 9 | `<Picture i>` |
| `ref_videos` | **IMAGE (ชุดเฟรม 24fps)** | 3 | `<Video k>` |
| `ref_video_audios` | AUDIO (จับคู่ตามเลข) | 3 | `<Audio j>` มาก่อน `<Video k>` ของมัน |
| `ref_audios` | AUDIO | 3 | `<Audio j>` |

ลำดับในการนำเสนอถูกล็อกไว้ในโหนด: **รูป → วิดีโอ → เสียงเดี่ยว**

### ต้นทุน token ที่วัดได้

| ref | token |
|---|---|
| ชีทตัวละคร 2 ใบ ที่ `ref_image_size="match"` | **1,550** |
| ชีทเดียวกันที่ `"max"` | 12,320 |
| วิดีโอ 124 เฟรม 360×640 | **14,000–27,000** |
| วิดีโอ 39 เฟรม 176×304 | 2,090 |

**ตัวที่หนักกว่าชนะ** ทดสอบสองครั้งด้วย seed เดียวกัน: ผลลัพธ์คือนักแสดงจากคลิปอ้างอิง ในเสื้อผ้าของเขา บนโซฟาของเขา ทั้งที่สั่งห้ามไว้ชัด

ทั้งสองวิธีนี้แพ้:
- **ห้าม** — *"do NOT take the faces, hair, clothing or room from it"*
- **สวมบทบาท** — *"the man in `<Video 1>` **is** `<Subject 1>` and wherever he appears he has this face"*

### สรุปการใช้
- ใช้ `ref_videos` เมื่ออยากได้**ทั้งฉาก** ไม่ใช่เมื่อต้องรักษาหน้าตัวละคร
- อยากยืมแค่ **"ลุค"** → **วัดแล้วเขียนตัวเลขลงพรอมป์ต** ได้ผลในครั้งเดียว ส่วน ref วิดีโอล้มเหลวสองครั้งและแพงกว่า 1.7 เท่า
- **ห้ามต่อ `ref_video_audios` จากคลิปที่หามาจากที่อื่น** — เป็นกับดักเดียวกับ ref เสียงรั่ว แต่มีบทพูดต่างภาษาเต็มไฟล์
- ถ้าจะดันจริง คันโยกที่ยังไม่ได้ลอง: `ref_image_size="max"` + ย่อวิดีโอ พลิกอัตราส่วนเป็น ~6:1 ฝั่งตัวละคร

## <a id="action"></a>โหมด action

ฉากแอ็กชันไม่ใช้ scaffold **เขียนเป็นย่อหน้าเดียว ไม่มี `[Shot N]` ไม่มี timestamp**

1. **ห้ามใส่ timestamp** — `[Shot N] At 00:02.750` คือการยื่นบล็อกเวลาตายตัวให้ H3 เติม คัต 0.3 วิ จะถูกยืดเป็น 42 เฟรม
2. **ฟิสิกส์มาก่อนคำขยาย** — ถ้าบีตไหนวาดออกมาอ่อน แปลว่าเหตุ-ผลไม่สมจริง (ลูกธนูดึงดาบหลุดจากสองมือไม่ได้ ต้องยิงโดนมือ)
3. **ทุกคัตต้องมีจุดเริ่มและจุดจบที่เรียกชื่อได้** เหมือนกฎกล้องที่ว่าการเคลื่อนกล้องต้องเดินทางจากสิ่งหนึ่งไปอีกสิ่ง
4. **ห้ามจอดบีตกล้องไว้กับของที่ไม่ขยับ**
5. **ห้ามเขียนคำที่สั่งให้ค้าง** — *"blades stop dead against each other"* ได้ดาบค้างจริง
6. กล้อง**นิ่ง**สำหรับจุดกระทบ · กล้อง**เดินทาง**ตามของที่ข้ามพื้นที่
7. **เศษที่ตามมาขายความเร็ว** (ฝุ่นเป็นอุโมงค์ คลื่นกระแทก ประกายไฟ) คำว่า "fast" ไม่ขาย

H3 ทำ motion ที่**ยกร่างคนทั้งตัว**ไม่ได้ — ยกขึ้นโต๊ะ อุ้ม พุ่งเข้าใส่ พลาดมาแล้วสามครั้ง **ตัดไปที่ผลลัพธ์แทนการแสดงการยก**

## <a id="chain"></a>การเชื่อมคลิป

ดึงเฟรมสุดท้ายด้วย
```bash
ffmpeg -y -sseof -0.5 -i clip.mp4 -update 1 last.png
```
แล้วคัดลอกเข้า `ComfyUI/input/` ก่อนต่อเป็น `<Picture N>`

**เลือกรูปแบบโซ่ตามว่าฉากเคลื่อนหรือไม่ — ผิดแบบแล้วพังคนละอาการ**

| | โซ่ต่อกัน (c1→c2→c3) | อ้างคลิป 1 ทั้งหมด |
|---|---|---|
| ฉากนิ่ง | สีเพี้ยนสะสม **L 107→86→74, sat 66→104→135** | ✅ |
| ฉากเคลื่อน | ✅ | ทุกคลิปย้อนกลับไปจุดเริ่ม |

### สิ่งที่ต้องเขียนใน `<Picture N>` ที่เป็นเฟรมเชื่อม

- เอาอะไร: ห้อง แสง ความสว่าง ความอิ่มสี **และคนไปถึงไหนแล้ว** (ใครยืนใครนั่ง ใครแตะใคร ใส่ชุดอะไร)
- **ห้ามปูห้อง**: *"this clip does NOT open by showing the room: no establishing shot, no wide view"*
- **ห้ามวาดคนซ้ำ**: *"anyone visible in `<Picture N>` is one of these same two men as they were a moment earlier, and they are NOT drawn again in the background"*
- **ห้ามย้อน**: *"nobody returns to how the scene started; the story only ever moves forward"*

## <a id="grade"></a>เกรดสี

วัดด้วย OpenCV: LAB สำหรับ L/a/b, HSV สำหรับ saturation — เฉลี่ยจากเฟรมที่สุ่มมาทั้งคลิป

| | อ้างอิงที่อนุมัติ | ค่า default ที่ผิด |
|---|---|---|
| L เฉลี่ย | **119** | 54 |
| saturation | **53** | 138 |
| b (128 = เป็นกลาง) | **133** | 140 |
| พิกเซล L<16 | **13.7%** | 26% |

ของ default **มืดกว่าครึ่งหนึ่งและอิ่มสีเกิน 2.6 เท่า** ความอิ่มสีคือครึ่งที่มองด้วยตาไม่เห็น

ถ้อยคำที่ให้ตัวเลขข้างบน:
> shot bright and high key … the image reads about **twice as bright as an ordinary interior** … colour **muted and milky, closer to pastel than to rich** … white balance **neutral and only barely warm**: no amber, no gold, no orange cast … contrast is **not flat**: whatever sits closest to the lens stays a **genuinely dark, almost black shape** against the bright room

**ฉากเป็นตัวกำหนดความสว่างพอๆ กับบล็อกเกรด** — บล็อกเกรดเดิม เปลี่ยนจากห้องกระดาษสาเป็นระเบียงชายคาลึก ได้ L ต่างกัน 30 หน่วย

**การเกลี่ยสีหลังบ้านเป็นแค่ตัวเก็บงาน** ไม่ใช่ทางแก้ Reinhard ใน LAB พลาดเพราะ gamut clamping (สั่งเกลี่ย 100% เหลือ −2.8) ต้องใช้ **histogram matching ใน RGB** ถึงจะเหลือ −1.9 แต่ที่ถูกคือแก้ที่ prompt

## <a id="failures"></a>อาการพังที่ไม่มีอะไรฟ้อง

| อาการ | ต้นเหตุ | แก้ |
|---|---|---|
| คลิปเปิดด้วยภาพกว้างปูห้อง | หัวช็อตเขียน `[Shot 1] The video opens on` ทุกคลิป | คลิปกลางฉากใช้ *"picks up in the middle of the scene, already in close, with no establishing view"* |
| ตัวละครซ้ำสองที่ในเฟรม | `<Picture N>` มีคนอยู่ + สั่งว่า "เอาห้องจากภาพนี้" | ล็อกว่า *"each of them appears exactly once in any frame; never a second copy"* — คำว่า "ห้ามมีคนที่สาม" ไม่ครอบ |
| ชุดกะพริบทุกคลิป | ข้อความบรรยายชุดขัดกับชีท ref | **ชีทชนะเสมอ** เขียนตามชีท |
| `an insert` ได้ภาพกว้าง | คำว่า insert ไม่มีน้ำหนัก | นำด้วยการตัดห้องออก: *"a macro shot held so close that the room, the walls and both men are entirely outside the frame, filled edge to edge by…"* |
| insert มีหน้าคนโผล่ | ผูก `<Subject N>` เข้ากับ insert | ห้ามผูก + เติม *"no face, no head and no eyes appear anywhere in the frame"* |
| H3 พูดคำที่ไม่ได้เขียน | ref เสียงที่ไม่มีบท | ถอด ref และถอด `<Audio N>` ออกจากพรอมป์ต |
| อ่านคำอธิบายออกมาดังๆ | อักษรไทยนอก `<d>` tag | regex เช็คก่อนเจน |
| ดนตรีโผล่มา | ก๊อป `non_diegetic_music` มาจากฉากอื่น | *"no score, no strings, no instrument of any kind"* — เรียกชื่อทีละอย่าง |

### คณิตศาสตร์ที่ทำให้เขียนไม่ได้

- คลิป 8 วิ ที่มี**ช็อตเงียบสองช็อต ทำสัดส่วนบทพูด 0.70 ไม่ได้เลย** — สองช็อตกินพื้น 2.5 วิ เหลือเพดานให้บทพูด 0.66
- การสแนป 0.25 วิ **ทิ้งเวลาได้ถึง 0.25 วิต่อจุดตัด** ในคลิป 8 วิคือ 9% มากพอจะทำให้สัดส่วนบทพูดตกเกณฑ์ทั้งที่จัดลงได้
- ความยาวคลิปที่ไม่ลงตัวกับ 0.25 (เช่น 10.125) ให้**ช็อตปิดรับเศษ** จุดตัดอื่นจะลงกริดครบ
- **อย่าคิดความยาวช็อตเอง** ใช้ `scripts/solve_shots.py` มันค้นทั้งกริด และถ้าไม่มีคำตอบมันบอกว่าต้องตัดกี่ตัวอักษร

### กับดักเครื่องมือ

- **patch script ที่ `str.replace` ไม่ match แล้วเงียบ** — เกิด 3 ครั้งในวันเดียว ส่งงานที่ไม่มีการแก้อยู่ในนั้นเลย **assert ว่าข้อความใหม่ปรากฏและข้อความเก่าหายไป** หรือเขียนไฟล์ใหม่ทั้งไฟล์
- **`kill -0` ใน Git Bash มองไม่เห็น PID ของ Windows** — เฝ้างานจากฝั่ง PowerShell ด้วย `Wait-Process`
- **`/system_stats` ของ ComfyUI รายงาน VRAM ผิด** — มันเห็นแค่ pool ของ torch ไม่เห็นส่วนที่ driver spill ใช้ `nvidia-smi` และดู **power draw**: 100% util ที่ 48 W คือกำลังรูด pagefile ไม่ใช่กำลังทำงาน
