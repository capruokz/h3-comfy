# H3 Prompt Engineering

`h3-drama` บอกว่า**ควรมีช็อตอะไรยาวเท่าไหร่** สกิลนี้บอกว่า**เขียนยังไงให้ H3 วาดตามนั้น**

## กฎเดียวที่อธิบายอาการพังได้เกือบทั้งหมด

> **H3 ก๊อป reference มันไม่ได้อ่าน และคำสั่งห้ามแทบไม่มีน้ำหนัก**
> ต้องบอกว่า**ให้เกิดอะไรขึ้นแทน** ไม่ใช่บอกว่าห้ามอะไร และต้องชนะด้วย**ปริมาณ token** ไม่ใช่ด้วยถ้อยคำ

วัดจริง: รูปตัวละคร 2 ใบที่ `ref_image_size="match"` = **1,550 token** · วิดีโออ้างอิง 124 เฟรม = **14,000–27,000 token**
ประโยคว่า *"do NOT take the faces from it"* แพ้ราบคาบ และการเขียนแบบสวมบทบาท (*"คนในวิดีโอคือ Subject 1"*) ก็แพ้เหมือนกัน

## โหมด prompt ห้าแบบ — เลือกก่อนเขียน

| โหมด | โครง | timestamp | พื้นบทพูด |
|---|---|---|---|
| **dialogue** | scaffold เต็ม | มี | 0.70 |
| **montage** | scaffold เต็ม ตัดไว | มี | 0.25 |
| **footage** | scaffold เต็ม ไม่มีใครพูด | มี | **0.0 — ต้องบันทึก EXEMPT** |
| **action** | **ย่อหน้าเดียว ไม่มี `[Shot N]`** | **ห้ามมี** | 0.45 |
| **product** | scaffold เต็ม มือล้วน | มี | 0.0 |

`action` เป็นโหมดเดียวที่ทิ้ง scaffold — timestamp ทำให้ H3 ยืดคัต 0.3 วิ ให้เต็ม 42 เฟรม ดู [REFERENCE.md](REFERENCE.md#action)

## ก่อนกดเจนทุกครั้ง

1. **โหมดไหน** และประกาศ `kind` ไว้ในสเปก
2. **เฟรมล็อกมั้ย** — `n=max(5,round(dur*24)); frames=n+(5-n%17)%17` · ค่าที่ลงตัว: **8.0 (DUR 8) · 10.125 (DUR 10) · 12.25 (DUR 12) · 15.0833 (DUR 15)** · **เพดานเฟรมขึ้นกับการ์ด** บนการ์ด 16 GB ที่เขียนเอกสารนี้อยู่ที่ ~294 เฟรม การ์ดที่ VRAM สูงกว่าไปได้ไกลกว่านั้น — สังเกตจากเวลาที่พุ่งเท่าตัวทั้งที่คลิปยาวขึ้นนิดเดียว
3. **ref ที่ไม่ได้ใช้ ถอดออก** — ref เสียงที่ไม่มีบทคือวิธีที่ H3 แต่งบทพูดขึ้นมาเอง คลิปไหนไม่มีใครพูด **อย่าต่อ และอย่าประกาศ `<Audio N>`**
4. **ชุดในข้อความต้องตรงกับชีท ref** ภาพชนะข้อความเสมอ ขัดกันเมื่อไหร่ชุดจะกะพริบทุกคลิป
5. **แสงอยู่ในเนื้อ shot ไม่ใช่หัว prompt** — เนื้อ shot เขียนทับหัวเสมอ grep หา `low sun` `warm light` `more orange` `golden` `dim` ก่อนเจน
6. **แก้กราฟต้องพิสูจน์ที่ 0.2 MP ก่อน** เหมือน `PROXY=1` ที่ใช้กับ prompt — กราฟพังได้แรงกว่า prompt
7. **`python scripts/solve_shots.py`** หาความยาวช็อต อย่าคิดเอง

## การเชื่อมคลิป — เลือกให้ถูกแบบ

| ฉาก | `<Picture N>` อ้างจาก | เหตุผล |
|---|---|---|
| **นิ่ง** ไม่มีใครขยับ (นั่งคุยกัน) | **คลิปที่ 1 ตลอด** | กันสีเพี้ยนสะสม โซ่ต่อกันทำให้ L ไหล 107→86→74 |
| **เดินหน้า** มีการเคลื่อนไหว | **คลิปก่อนหน้าเสมอ** | อ้างคลิป 1 = สั่งให้ย้อนกลับไปจุดเริ่มทุกคลิป |

และคลิปที่ 2 เป็นต้นไป **ห้ามขึ้นต้นว่า `The video opens on`** — สั่งให้เปิดวิดีโอ H3 จะปูห้องกว้างให้ แม้ช็อตนั้นจะเขียนว่า extreme close-up ก็ตาม

## เกรดสี: วัด อย่าบรรยาย

คำว่า warm / moody / high key ไม่เคยเข้าเป้า **วัดคลิปอ้างอิงแล้วเขียนตัวเลขลงไป**
ค่าที่ผู้กำกับอนุมัติ: **L 119 · saturation 53 · b 133 · ยังมีดำ 13.7%**
ห้ามเขียน "ไม่มีอะไรจมดำ" — คลิปที่ดูดีมีดำจริง มันยก **midtone** ไม่ใช่ยกเงา

## อาการพังที่ไม่มีอะไรฟ้อง

ทุกข้อเคยเกิดจริงและกินเวลาเจนไปแล้ว รายละเอียดใน [REFERENCE.md](REFERENCE.md#failures)

- คลิปเปิดด้วยภาพกว้างปูห้อง → หัวช็อตเขียนว่า "opens"
- ตัวละครโผล่ซ้ำสองที่ในเฟรมเดียว → ref เฟรมมีคนอยู่ และสั่งว่า "เอาห้องจากภาพนี้"
- ชุดเปลี่ยนสีทุกคลิป → ข้อความขัดกับชีท ref
- `an insert` ออกมาเป็นภาพกว้าง → ต้องตัดห้องออกก่อนค่อยบอกว่ามีอะไรในเฟรม
- ดาบฟันค้าง / มั่ว → เขียนคำที่สั่งให้ค้าง หรือคัตไม่มีจุดเริ่ม-จุดจบที่เรียกชื่อได้
- H3 พูดภาษาแปลก → ref เสียงที่ไม่มีบท หรือมีอักษรไทยนอก `<d>` tag
- **patch script ที่ replace ไม่ match แล้วเงียบ** → เกิด 3 ครั้งในวันเดียว ส่งงานที่ไม่มีการแก้อยู่ในนั้นเลย **assert ว่าข้อความใหม่ปรากฏจริง**

## ตอนส่งงาน

**เปิดดูก่อนส่ง** — เช็ครอยต่อทุกจุด (เฟรมสุดท้ายคลิป N คู่กับเฟรมแรกคลิป N+1), หาคนซ้ำ, แล้วค่อยส่ง
ตำหนิเล็กน้อยไม่ต้องเจนซ้ำ แต่ฉากไม่ต่อกันคือของเสีย
