# ติดตั้ง H3

**ถ้ากำลังช่วยคนที่ไม่คุ้นเทอร์มินัล ให้เดินตาม [guides/](../../guides/) แทนหน้านี้**
หน้านี้เขียนย่อสำหรับคนที่รู้อยู่แล้วว่ากำลังทำอะไร คู่มือในนั้นจับมือทำทีละขั้นพร้อมรูป

## ขอบเขต: การ์ด Blackwell เท่านั้น

รองรับ **RTX 50 ซีรีส์ · RTX PRO 6000 Blackwell · B200** (compute capability ≥ 10.0)
การ์ดเก่ากว่านี้ `check_stack.py` จะปฏิเสธพร้อมบอกวิธีเปลี่ยนเครื่อง

**เป็นการจำกัดขอบเขตโดยตั้งใจ ไม่ใช่ข้อจำกัดทางเทคนิค** — ตัวเลขทุกตัวในชุดนี้วัดจาก
ตระกูลนี้ จึงรับประกันเฉพาะตระกูลนี้ ถ้าผู้ใช้ยืนยันจะลองบนการ์ดเก่า ทางออกคือ `FORCE=1`
และต้องบอกเขาว่าตัวเลขในเอกสารเทียบไม่ได้แล้ว **อย่าแก้เกณฑ์ในสคริปต์ให้หลวมลงเพื่อ
ให้เครื่องหนึ่งผ่าน** — นั่นทำให้คนถัดไปเชื่อตัวเลขที่ไม่มีใครวัด

## ลำดับที่ห้ามสลับ

```bash
export HF_TOKEN=hf_xxxx
bash setup.sh          # ตรวจก่อน → โหลด → node → แพตช์ → restart
python3 find_ceiling.py
```

**ตรวจสแต็กมาก่อนโหลดโดยตั้งใจ** เครื่องที่ตั้งค่าผิดยังเจนคลิปออกมาได้ปกติ ไม่มี error
แค่ช้ากว่าที่ควรหลายเท่า — ที่บ้านเคยเสียไปครึ่งวันเพราะ SageAttention ยังเป็น 1.0.6
(ไม่มี path ของ Blackwell) บวก torch ที่ build กับ CUDA 12.8 รวมกันช้ากว่าที่ควร **5.2 เท่า**
ถ้าปล่อยให้โหลด 38 GB จบก่อนค่อยรู้ ก็จ่ายค่าเช่าไปแล้ว

## สิ่งที่แต่ละสคริปต์แก้

| สคริปต์ | แก้ปัญหาอะไร |
|---|---|
| `check_stack.py` | ยืนยันว่าเป็น cu130 + SageAttention ≥2.2 ก่อนจ่ายค่าโหลด |
| `comfy_env.sh` | **หา ComfyUI ตัวที่รันอยู่จริง** เทมเพลต vast มีสองชุดบนดิสก์ ตัวที่ `[ -d ]` เจอก่อนไม่ใช่ตัวที่ให้บริการ เคยทำให้ 38 GB ลงผิดที่ |
| `setup.sh` | โหลดโมเดล + clone node ที่ล็อกคอมมิต + แพตช์ + restart |
| `find_ceiling.py` | **หาเพดานเฟรมของการ์ดใบนี้เอง** ไม่ใช่เชื่อตัวเลขในเอกสาร |
| `h3turbo_patched__init__.py` | โหนด turbo ต้นฉบับตายทันทีที่ต่อ `<Audio N>` เดี่ยว — `_unique_t` สร้างแถว timestep น้อยกว่า core หนึ่งแถว คลิปที่มีบทพูดจึงรันไม่ได้เลย |

## กับดักของเครื่องเช่าที่ต้องรู้

- **ComfyUI สองชุด** ตัวที่รันอยู่ไม่ใช่ตัวที่หาเจอก่อน → ใช้ `comfy_env.sh` เสมอ อย่าเดา path
- **พอร์ตที่เห็นไม่ใช่พอร์ตจริง** แอปฟังที่ 18188 ส่วน 8188 เป็น proxy ที่มี auth คั่นอยู่
  สั่งเปิด "ที่ 8188" จะตายทันทีเพราะพอร์ตชน
- **มี supervisor คอยเปิดใหม่ให้** `pkill` แล้วเปิดเองจะแพ้การแข่งขัน ไปคุยกับโปรเซสเก่า
  → ใช้ `restart_comfy.sh`
- **nvcc มีแต่เฮดเดอร์ CUDA ไม่ครบ** build SageAttention ตายที่ `cusparse.h` →
  `--fix` ชี้ไปที่เฮดเดอร์ในล้อ nvidia ของ torch ก่อน ค่อยไป apt
- **ComfyUI อ่านรายชื่อโมเดลครั้งเดียวตอนบูต** โหลดโมเดลหลังเปิดเซิร์ฟเวอร์แล้วมันมองไม่เห็น

## เรื่องเพดานเฟรม — จุดที่คนเอาไปใช้ต่อพลาดง่ายที่สุด

อาการล้น VRAM **ไม่ error** คลิปยังออกมาครบ แค่ต้นทุนต่อเฟรมพุ่ง วัดได้บนการ์ด 16 GB ใบหนึ่ง:
294 เฟรม = 1.24 วิ/เฟรม แต่ 362 เฟรม = **3.27 วิ/เฟรม** ทั้งที่เรนเดอร์ผ่านทั้งคู่

**ตัวเลข 294 นั้นเป็นของการ์ดใบนั้น ไม่ใช่ของทุกใบ** — อย่าเอาไปเขียนเป็นกฎ

วิธีจับว่าล้นคือดู **กำลังไฟ** ไม่ใช่ VRAM: การ์ดที่ทำงานจริงกินไฟใกล้ค่าสูงสุด
ส่วนการ์ดที่รูดข้อมูลกับ RAM จะขึ้น util 100% แต่กินไฟแค่ **48 W บนการ์ด 180 W**
`/system_stats` ของ ComfyUI เชื่อไม่ได้ตรงนี้ มันเห็นแค่ pool ของ torch ไม่เห็นส่วนที่ driver
ดันออก RAM — `find_ceiling.py` จึงอ่านจาก `nvidia-smi`

## ความยาวคลิปที่ลงตัว

`frames = n + (5 - n%17)%17` เมื่อ `n = max(5, round(วินาที*24))`
ค่าที่ลงตัวพอดี: **8.0 · 10.125 · 12.25 · 15.0833 วินาที** ความยาวอื่นจะถูกปัดขึ้น
