# คู่มือ 4 — ติดตั้งลงเครื่อง Windows ของตัวเอง

คู่มือนี้สำหรับคนที่**มีการ์ด RTX 50 ซีรีส์อยู่ในเครื่องแล้ว** และอยากลงไว้ใช้เอง
ไม่ต้องเช่าเครื่อง

ถ้าไม่มีการ์ดรุ่นนั้น ไปที่ [คู่มือ 1 — เช่าเครื่อง](01-rent-vast.md) แทน

**จะกินพื้นที่เท่าไหร่** — ComfyUI ราว 5 GB + ไฟล์โมเดล 38 GB รวม **ประมาณ 45 GB**
ทั้งหมดอยู่ในโฟลเดอร์เดียว ถ้าวันหลังไม่เอาแล้วก็ลบโฟลเดอร์นั้นทิ้งได้เลย ไม่มีอะไรค้างที่อื่น

**จะใช้เวลาเท่าไหร่** — ราว 30–60 นาที ขึ้นกับความเร็วเน็ต ส่วนใหญ่คือรอโหลด

---

## ต้องมีก่อน

**Git** — ถ้ายังไม่มี โหลดที่ https://git-scm.com/download/win แล้วติดตั้งแบบกดถัดไปรวด
ไม่ต้องเปลี่ยนอะไร

เช็คว่ามีแล้วหรือยัง เปิด PowerShell แล้วพิมพ์ `git --version` ถ้าขึ้นเลขเวอร์ชันคือมีแล้ว

---

## ขั้นที่ 1 — เปิด PowerShell

กดปุ่ม Windows แล้วพิมพ์ **PowerShell** กด Enter

> **ต้องเป็น PowerShell ไม่ใช่ Command Prompt (cmd)** สองอันหน้าตาคล้ายกันมาก
> ทั้งคู่เป็นจอดำมีตัวหนังสือ แต่คำสั่งคนละชุดกัน
>
> **วิธีดูว่าเปิดถูกมั้ย** บรรทัดบนสุดจะขึ้นต้นด้วย `PS ` เช่น `PS C:\Users\ชื่อคุณ>`
> ถ้าไม่มี `PS` นำหน้า แสดงว่าเปิด cmd มา ให้ปิดแล้วเปิดใหม่

---

## ขั้นที่ 2 — ดึงชุดติดตั้ง

ก๊อปทั้งบล็อกนี้ไปวางแล้วกด Enter

```powershell
cd $env:USERPROFILE
git clone https://github.com/capruokz/h3-comfy
cd h3-comfy\skills\h3-setup\scripts
```

**จะเห็นอะไรตอนสำเร็จ** — มีข้อความ `Cloning into 'h3-comfy'...` แล้วบรรทัดสุดท้าย
เปลี่ยนเป็น `...\h3-comfy\skills\h3-setup\scripts>` ใช้เวลาไม่กี่วินาที

---

## ขั้นที่ 3 — ตรวจเครื่องก่อน

```powershell
python precheck.py
```

ถ้าขึ้นว่าไม่รู้จักคำสั่ง `python` แปลว่าเครื่องยังไม่มี Python
ลงจาก https://www.python.org/downloads/ **ตอนติดตั้งอย่าลืมติ๊กช่อง Add to PATH**
แล้วปิด PowerShell เปิดใหม่

**อ่านผลยังไง**

| ขึ้นว่า | ทำยังไงต่อ |
|---|---|
| `[ผ่าน]` ทุกบรรทัด แล้วจบด้วย `เครื่องนี้ติดตั้งได้` | ไปขั้นที่ 4 |
| `ติดตั้งบนเครื่องนี้ไม่ได้` | อ่านเหตุผลที่มันบอก ส่วนใหญ่คือการ์ดไม่ใช่รุ่น 50 หรือพื้นที่ไม่พอ |

ถ้าการ์ดไม่ผ่าน **ยังไม่ต้องเสียใจ** เช่าเครื่องเอาก็ได้ ชั่วโมงละราว 20–40 บาท
ดู [คู่มือ 1](01-rent-vast.md)

## ขั้นที่ 4 — ลง ComfyUI

```powershell
powershell -ExecutionPolicy Bypass -File install_comfy.ps1
```

**`-ExecutionPolicy Bypass` คืออะไร** — ปกติ Windows ไม่ยอมให้รันสคริปต์ที่โหลดมา
เพื่อความปลอดภัย คำสั่งนี้บอกว่า "ไฟล์นี้ฉันตรวจแล้ว รันได้" **เฉพาะครั้งนี้ครั้งเดียว**
ไม่ได้เปลี่ยนการตั้งค่าเครื่องถาวร

อยากลงที่อื่นก็เติมท้ายได้ เช่น `-Dest D:\AI`

มันจะ:
1. ถามหน้า release ว่ารุ่นล่าสุดชื่ออะไร
2. โหลดไฟล์ราว **2 GB**
3. แตกไฟล์ด้วย `tar` ที่ติดมากับ Windows อยู่แล้ว (ไม่ต้องลง 7-Zip)
4. เปิด ComfyUI แล้วรอจนมันตอบ

**จะเห็นอะไรตอนสำเร็จ**

```
ComfyUI พร้อมแล้วที่ C:\ComfyUI\ComfyUI_windows_portable\ComfyUI  (พอร์ต 8188)
เปิดหน้าเว็บได้ที่ http://127.0.0.1:8188
```

ลองเปิดลิงก์นั้นในเบราว์เซอร์ดูได้ ถ้าเห็นหน้าจอ ComfyUI แปลว่าใช้ได้แล้ว

## ขั้นที่ 5 — ใส่รหัสโหลดโมเดล

ยังไม่มี HF token? ทำตาม [คู่มือ 2](02-hf-token.md) ก่อน ใช้เวลาไม่ถึง 2 นาที

```powershell
$env:HF_TOKEN = "hf_xxxx"
```

แทนที่ `hf_xxxx` ด้วย token ของคุณ **จะไม่มีอะไรขึ้นเลย นั่นคือปกติ**

> **ถ้าปิด PowerShell แล้วเปิดใหม่ ต้องพิมพ์บรรทัดนี้ใหม่** มันไม่ได้จำข้ามหน้าต่าง

---

## ขั้นที่ 6 — ลงโมเดล

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
```

**ใช้เวลา 20–50 นาที** โหลด 38 GB ปล่อยมันไป อย่าปิดหน้าต่าง

**จะเห็นอะไรตอนสำเร็จ** — บรรทัดสุดท้ายขึ้นคำว่า

```
ready
```

เสร็จแล้ว เจนคลิปได้เลยที่ http://127.0.0.1:8188

## แก้ปัญหาที่เจอบ่อย

**`ไม่รู้จักคำสั่ง git`**
→ ยังไม่ได้ลง Git หรือลงแล้วแต่ยังไม่ได้เปิด PowerShell ใหม่ ปิดแล้วเปิดใหม่ก่อน

**`running scripts is disabled on this system`**
→ ลืมใส่ `-ExecutionPolicy Bypass` ข้างหน้า ใส่ให้ครบตามที่เขียนไว้

**`ไม่พบ nvidia-smi`**
→ ไดรเวอร์การ์ดจอยังไม่ได้ลงหรือเก่าเกินไป โหลดจากเว็บ NVIDIA แล้วรีสตาร์ทเครื่อง

**โหลดโมเดลแล้วขึ้น `401` หรือ `403`**
→ ยังไม่ได้กดยอมรับเงื่อนไขของโมเดล ทำตาม [คู่มือ 2 ขั้นที่ 3](02-hf-token.md)

**ComfyUI ไม่ตอบ / เปิดหน้าเว็บไม่ได้**
→ ดูสาเหตุที่ไฟล์ `comfy.log` ในโฟลเดอร์ `ComfyUI_windows_portable`

**อยากลบทิ้งทั้งหมด**
→ ลบโฟลเดอร์ `C:\ComfyUI` (หรือที่ที่คุณเลือกไว้) กับโฟลเดอร์ `h3-comfy` ทิ้ง จบ
ไม่มีอะไรค้างในระบบ
