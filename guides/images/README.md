# รูปที่ต้องถ่าย

รูปในโฟลเดอร์นี้ยังไม่มี คู่มือลิงก์ไว้แล้วรอเติม

## กติกาของรูปในชุดนี้

1. **ลงวันที่ที่ถ่ายไว้ในคำบรรยายใต้รูปทุกใบ** เว็บพวกนี้เปลี่ยนหน้าตาบ่อย รูปที่ไม่รู้ว่า
   ถ่ายเมื่อไหร่จะกลายเป็นตัวหลอกแทนที่จะช่วย
2. **คู่กับรูปต้องมีข้อความบอกสิ่งที่ต้องมองหา ไม่ใช่ตำแหน่งบนจอ** เขียนว่า
   "ช่องที่เขียนว่า Token type" ไม่ใช่ "ปุ่มสีฟ้ามุมขวาบน" เพราะปุ่มย้ายที่ได้ แต่ป้ายชื่อ
   มักอยู่นานกว่า
3. **ปิดทับข้อมูลส่วนตัวก่อนเสมอ** — ยอดเงิน อีเมล ชื่อบัญชี เลขบัตร เลข IP และ**ตัว token**
4. วงหรือใส่ลูกศรชี้จุดที่ต้องดู อย่าปล่อยให้ผู้อ่านหาเอง
5. ตัดเฉพาะส่วนที่เกี่ยวข้อง ไม่ต้องเอาทั้งหน้าจอ

**ไม่ต้องถ่ายหน้าจอผลลัพธ์ในเทอร์มินัล** ข้อความพวกนั้นอยู่ในคู่มือเป็นบล็อกข้อความแล้ว
ซึ่งดีกว่ารูป: ไม่ล้าสมัย ค้นหาเจอ และผู้อ่านเอาไปเทียบกับของตัวเองได้ตรงๆ

---

## รายการที่ต้องถ่าย — 5 ใบ

### 1. `01-vast-search.png` — หน้าเลือกเครื่อง
**ถ่ายที่** vast.ai → Search
**ใบที่สำคัญที่สุดในชุด** เพราะเลือกผิดตรงนี้คือเสียเงินฟรี

ต้องเห็นในรูป:
- **ชื่อรุ่นการ์ด** ← สำคัญที่สุด ต้องเห็นชัดว่าตรงไหนบอกรุ่น (ต้องขึ้นต้นด้วย 50)
- VRAM
- Disk
- ความเร็วเน็ต (Mbps)
- ค่า bandwidth

ถ้าเป็นไปได้ **ถ่ายให้มีทั้งเครื่องที่ใช้ได้และใช้ไม่ได้อยู่ในรูปเดียวกัน** แล้ววงเขียวกับแดง
จะสอนได้ในภาพเดียวว่าดูตรงไหน

ปิด: ยอดเงินคงเหลือมุมบน

---

### 2. `02-vast-template.png` — หน้าเลือกเทมเพลต
**ถ่ายที่** ตอนกดเช่า ก่อนยืนยัน
ต้องเห็น: รายการเทมเพลตที่มีตัวเลือกซึ่งชื่อมีคำว่า **ComfyUI**
ปิด: ไม่มีอะไรเป็นพิเศษ

> ใบนี้เพิ่งเพิ่มเข้ามา ยังไม่มีในคู่มือ — ถ้าถ่ายมาผมจะแทรกให้ในขั้นที่ 2 ของคู่มือ 1

---

### 3. `03-vast-instance-ready.png` — เครื่องพร้อมแล้ว
**ถ่ายที่** vast.ai → Instances
ต้องเห็น: สถานะที่บอกว่าพร้อม + ปุ่มที่กดเข้า Jupyter + **ปุ่ม Destroy**
(ให้เห็นตั้งแต่ต้นว่าเลิกใช้ต้องกดตรงไหน)
ปิด: เลข IP, ยอดเงิน, อีเมล

---

### 4. `04-jupyter-terminal.png` — Terminal ไม่ใช่ Notebook
**ถ่ายที่** หน้า Jupyter หลังเปิดเข้ามา
**จุดที่คนพลาดมากที่สุดในคู่มือทั้งชุด**

ต้องเห็น: ไอคอน **Terminal** และไอคอน **Notebook / Python 3** อยู่ในรูปเดียวกัน
เพื่อให้เห็นว่าอันไหนคืออันไหน — วงเขียวที่ Terminal วงแดงที่ Notebook
ปิด: ชื่อผู้ใช้ในหัวหน้าเว็บ

---

### 5. `05-hf-token-create.png` — สร้าง token
**ถ่ายที่** huggingface.co/settings/tokens ตอนกดสร้าง
ต้องเห็น: ช่องตั้งชื่อ + ช่องเลือกประเภทที่มีคำว่า **Read** (วงไว้)
**ปิด: ตัว token ทั้งหมด ปิดให้มิด**

> ใบนี้ต้องระวังที่สุด ถ้าถ่ายมาแล้วมี token โผล่ เราจะกำลังสอนเรื่องความปลอดภัย
> ด้วยรูปที่ละเมิดมันเอง — และคนที่ก๊อป repo ไปจะได้ token คุณติดไปด้วย
>
> ถ้าถ่ายตอน token โชว์อยู่แล้วเผลอ push ขึ้น git ให้ถือว่า token นั้นหลุดแล้ว
> ไปกดลบที่หน้าเดิมทันที การลบไฟล์ทีหลังไม่ช่วย เพราะ git เก็บประวัติไว้
