# คู่มือ 2 — เอารหัสสำหรับโหลดโมเดล (HF token)

**Hugging Face คืออะไร** — เว็บที่เก็บไฟล์โมเดล AI ให้คนโหลดไปใช้ ไฟล์โมเดล H3 ที่เราต้องใช้
อยู่ที่นั่น

**ทำไมต้องมีรหัส** — โหลดโดยไม่มีรหัสก็ได้ แต่จะโดนจำกัดความเร็ว และบางไฟล์ต้องกดยอมรับ
เงื่อนไขก่อนถึงจะโหลดได้ ซึ่งต้องล็อกอิน เราจ่ายค่าเช่าเครื่องอยู่ระหว่างรอโหลด
รหัสนี้จึงคุ้มค่าที่จะทำ ใช้เวลาไม่ถึง 2 นาที

**token คืออะไร** — สายอักขระยาวๆ ที่ใช้แทนการล็อกอิน **มันคือรหัสผ่านของคุณ**

---

## กฎความปลอดภัย อ่านก่อน

- **อย่าส่ง token ให้ใคร** ไม่ต้องแปะในแชท ไม่ต้องส่งให้ AI ไม่ต้องถ่ายรูปหน้าจอที่มีมัน
- ถ้าจะขอความช่วยเหลือแล้วต้องส่งภาพหน้าจอ **ให้ปิดทับส่วนที่เป็น token ก่อนเสมอ**
- **ถ้าเผลอให้ใครเห็นแล้ว ให้กดลบทิ้งทันที** ที่หน้าเดิม แล้วสร้างอันใหม่ ใช้เวลาไม่ถึงนาที
  และไม่มีผลเสียอะไรเลย ที่แย่กว่าคือปล่อยอันที่หลุดไว้เฉยๆ

---

## ขั้นที่ 1 — สมัคร Hugging Face

เข้า https://huggingface.co แล้วสมัคร ใช้อีเมลอย่างเดียวก็ได้ ไม่ต้องผูกบัตร ไม่เสียเงิน

---

## ขั้นที่ 2 — สร้าง token

1. ล็อกอินแล้วเข้า https://huggingface.co/settings/tokens
2. กดปุ่ม **Create new token**

จะขึ้นฟอร์มมาให้กรอก มีสามส่วนเรียงจากบนลงล่าง:

```
  Token type                       ← ส่วนที่ 1 สำคัญที่สุด
  ( ) Fine-grained
  (•) Read          ← เลือกอันนี้
  ( ) Write

  Name                             ← ส่วนที่ 2
  [ h3-comfy                     ]

                        [ Create token ]   ← ส่วนที่ 3 กดตอนท้าย
```

3. **ส่วน `Token type` เลือก `Read`** — ถ้าหน้าเว็บให้เลือกแค่ Fine-grained กับ Read
   ก็เลือก Read ถ้าไม่เห็นส่วนนี้เลย แปลว่าเวอร์ชันนั้นให้ Read มาเป็นค่าเริ่มต้นอยู่แล้ว
4. **ส่วน `Name` ตั้งชื่ออะไรก็ได้ที่คุณจำได้** เช่น `h3-comfy` ชื่อนี้ไม่มีผลอะไร
   มีไว้ให้คุณรู้เองว่า token ตัวไหนใช้ทำอะไร เผื่อวันหลังจะลบ

> **ทำไมต้อง Read** เพราะเราแค่จะโหลดไฟล์ลงมา ไม่ได้จะอัปโหลดอะไรขึ้นไป
> ถ้าเลือกแบบที่เขียนได้ (Write) แล้ว token หลุด คนที่ได้ไปจะแก้ไฟล์ในบัญชีคุณได้ด้วย
> **ให้สิทธิ์น้อยที่สุดเท่าที่งานต้องใช้เสมอ**

5. กดสร้าง จะได้สายอักขระขึ้นต้นด้วย `hf_` ยาวๆ

> **ตัวนี้จะโชว์ครั้งเดียว** ปิดหน้าไปแล้วจะดูย้อนไม่ได้ ถ้าลืมก็แค่สร้างอันใหม่ ไม่เป็นไร
> ก๊อปเก็บไว้ก่อน แต่**อย่าเก็บในไฟล์ที่จะแชร์ให้คนอื่น**

---

## ขั้นที่ 3 — กดยอมรับเงื่อนไขของโมเดล

โมเดลบางตัวต้องกดยอมรับก่อนถึงจะโหลดได้ ถ้าไม่กด สคริปต์จะโหลดไม่ผ่านและขึ้น
`401` หรือ `403` ทั้งที่ token ถูกต้อง

เปิดสามลิงก์นี้ทีละอัน ถ้าเจอปุ่มให้กดยอมรับก็กด ถ้าไม่เจอแปลว่าไม่ต้องทำอะไร:

- https://huggingface.co/Comfy-Org/MiniMax-H3
- https://huggingface.co/tsolful/Minimax_H3_INT4MixedConvRot
- https://huggingface.co/larryvrh/MiniMax-H3-Turbo-Lora

## ขั้นที่ 4 — เอา token ใส่เครื่องที่เช่ามา

กลับไปที่จอดำ (Terminal) ในหน้า Jupyter จากคู่มือ 1 แล้ววางบรรทัดนี้
โดย**แทนที่ `hf_xxxx` ด้วย token ของคุณ**

```bash
export HF_TOKEN=hf_xxxx
```

กด `Enter` **จะไม่มีอะไรขึ้นเลย นั่นคือปกติ** คำสั่งนี้ไม่แสดงผลอะไรเมื่อสำเร็จ

อยากเช็คว่าใส่แล้วจริงมั้ย พิมพ์:

```bash
echo ${HF_TOKEN:0:6}...
```

ถ้าขึ้นว่า `hf_xxx...` แปลว่าใช้ได้แล้ว (คำสั่งนี้โชว์แค่ 6 ตัวแรก ตั้งใจให้ไม่โชว์ทั้งอัน)

> **จุดที่คนพลาด** ถ้าปิดจอดำแล้วเปิดใหม่ ต้องพิมพ์ `export HF_TOKEN=...` ใหม่อีกครั้ง
> มันไม่ได้จำข้ามหน้าต่าง
