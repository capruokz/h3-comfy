# คู่มือ 1 — เช่าเครื่องบน vast.ai

คู่มือนี้เขียนสำหรับคนที่ไม่เคยเช่า GPU มาก่อน ทำตามทีละขั้นได้เลย

**vast.ai คืออะไร** — เว็บที่ให้เราเช่าคอมพิวเตอร์ที่มีการ์ดจอแรงๆ เป็นรายชั่วโมง
เราไม่ต้องซื้อการ์ดเอง เปิดใช้เสร็จก็ปิด จ่ายเท่าที่ใช้

**จะใช้เงินเท่าไหร่** — การ์ดที่เหมาะกับงานนี้ตกราวชั่วโมงละ 20–40 บาท บวกค่าโหลดไฟล์
อีกครั้งเดียวตอนติดตั้ง ลองครั้งแรกเผื่อไว้ราว 100 บาทก็พอ

---

## ขั้นที่ 1 — สมัครแล้วเติมเงิน

1. เข้า https://vast.ai แล้วสมัคร
2. เติมเงินเข้าบัญชี (Billing → Add Credit) ขั้นต่ำมักอยู่ที่ $5

> **เตือน** เว็บนี้เป็นเว็บจ่ายเงินจริง ให้กรอกข้อมูลบัตรเองเท่านั้น
> ถ้าคุณให้ AI ช่วยทำขั้นตอนนี้ **อย่าพิมพ์เลขบัตรลงในแชท**

## ขั้นที่ 2 — เลือกเครื่อง (ขั้นที่พลาดกันบ่อยที่สุด)

ไปที่หน้า **Search** จะเจอรายการเครื่องยาวเป็นหางว่าว มีตัวเลขเต็มไปหมด
**ดูแค่ 5 อย่างนี้พอ** ที่เหลือไม่ต้องสนใจ

แต่ละเครื่องคือหนึ่งแถวยาวๆ ในแถวหนึ่งจะมีของพวกนี้เรียงกันอยู่ หน้าตาประมาณนี้:

```
┌──────────────────────────────────────────────────────────────────────┐
│  1x RTX 5090     32.6 GB      $0.44/hr                               │
│  ▲               ▲            ▲                                      │
│  │               │            └── ค่าเช่าต่อชั่วโมง (ยังไม่รวมค่าเน็ต)   │
│  │               └── VRAM                                            │
│  └── ชื่อรุ่น ← ดูตัวนี้ก่อนเพื่อน ต้องขึ้นต้นด้วย 50                    │
│                                                                      │
│  1274.5 Mbps ↓    500 GB Disk    $0.012/GB                           │
│  ▲                ▲              ▲                                   │
│  │                │              └── ค่าเน็ต คิดตามที่โหลด            │
│  │                └── พื้นที่                                         │
│  └── ความเร็วเน็ต                                                     │
└──────────────────────────────────────────────────────────────────────┘
```

ตำแหน่งที่วางอาจไม่เหมือนกันเป๊ะ แต่**ตัวเลขหน่วยจะบอกเองว่าอันไหนคืออันไหน**:
`GB` ตัวเดียวโดดๆ คือ VRAM · `Mbps` คือความเร็วเน็ต · `GB Disk` คือพื้นที่ ·
`$/hr` คือค่าเช่า · `$/GB` คือค่าเน็ต

| ดูอะไร | ต้องได้เท่าไหร่ | ทำไม |
|---|---|---|
| **VRAM** (หน่วยความจำการ์ดจอ) | **16 GB ขึ้นไปใช้ได้ · 24 GB ขึ้นไปสบาย** | ตัวเลขนี้กำหนดว่าคลิปยาวได้แค่ไหน ไม่ได้กำหนดว่าใช้ได้หรือไม่ได้ ดูตารางข้างล่าง |
| **Disk** (พื้นที่) | **อย่างน้อย 100 GB** | ไฟล์โมเดลรวมกัน 38 GB ต้องมีที่เหลือให้คลิปที่เจนออกมาด้วย |
| **ความเร็วเน็ต** (Mbps) | **อย่างน้อย 1000** | เราจ่ายค่าเช่าอยู่ระหว่างที่รอโหลด เครื่องที่เน็ต 170 Mbps จะเผาเวลาไป ~30 นาทีทุกครั้งที่เปิดใหม่ |
| **ค่าเน็ต** (bandwidth) | ยิ่งถูกยิ่งดี | ราคาที่โชว์หน้าแรกยังไม่รวมค่าโหลดไฟล์ บางเจ้าคิดค่าโหลดแพงกว่าค่าเช่าอีก และเราต้องโหลด 38 GB |

### สำคัญที่สุด — ต้องเป็นการ์ด RTX 50 ซีรีส์เท่านั้น

**นี่คือข้อที่พลาดแล้วเสียเงินฟรี อ่านก่อนกดเช่า**

ชุดนี้รองรับเฉพาะการ์ด NVIDIA ตระกูล **Blackwell** ซึ่งก็คือ **RTX รุ่นที่ขึ้นต้นด้วย 50**

| ใช้ได้ ✅ | ใช้ไม่ได้ ❌ |
|---|---|
| RTX **50**60 Ti · **50**70 · **50**70 Ti · **50**80 · **50**90 | RTX 4090 · 4080 · 4070 (ขึ้นต้นด้วย 40) |
| RTX PRO 6000 Blackwell · B200 | RTX 3090 · 3080 (ขึ้นต้นด้วย 30) |
| | A100 · H100 · L40S · A10 · A6000 · T4 |

**วิธีจำง่ายๆ: เลขรุ่นต้องขึ้นต้นด้วย 50**

**วิธีค้น** ที่หน้า Search มีช่องกรองรุ่นการ์ด พิมพ์ `5090` หรือ `5080` หรือ `5060`
แล้วเลือกจากที่ขึ้นมา

> **ทำไมถึงจำกัดแค่นี้** ตัวเลขทุกตัวในคู่มือชุดนี้ — คลิปยาวได้เท่าไหร่ ใช้เวลาเจนนานแค่ไหน —
> วัดมาจากการ์ดตระกูลนี้ การ์ดรุ่นเก่ากว่ารันได้เหมือนกัน แต่เราไม่มีตัวเลขที่วัดเองยืนยัน
> จึงไม่อยากให้ใครเอาไปวางแผนงานแล้วผิดคาด

**ถ้าเพิ่งลองครั้งแรก เลือก RTX 5090 ที่ราคาถูกที่สุด** — VRAM 32 GB เหลือเฟือ
ไม่ต้องมานั่งเดาว่าคลิปยาวเกินไปหรือเปล่า

### VRAM บอกอะไร

VRAM ไม่ได้บอกว่าใช้ได้หรือไม่ได้ แต่บอกว่า**คลิปยาวได้แค่ไหน**

| VRAM | การ์ด | ได้อะไร |
|---|---|---|
| 16 GB | RTX 5060 Ti | ใช้ได้จริง เป็นการ์ดที่ใช้เขียนคู่มือชุดนี้ทั้งหมด แต่คลิปยาวๆ จะช้าลงมาก |
| 24 GB | RTX 5080 Super / 5070 Ti Super | สบาย |
| **32 GB** | **RTX 5090** | **คุ้มที่สุดสำหรับงานนี้** |

หลังติดตั้งเสร็จจะมีขั้นตอนวัดเพดานของการ์ดใบที่คุณได้จริงๆ อยู่แล้ว
([คู่มือ 3](03-install.md) ขั้นที่ 4) ไม่ต้องเดาเอง

> ถ้าเผลอเช่าการ์ดรุ่นเก่ามา ขั้นตอนตรวจเครื่องจะบอกก่อน**ตั้งแต่ยังไม่ได้โหลดไฟล์ 38 GB**
> จึงเสียแค่ค่าเช่าไม่กี่นาที ไม่ใช่ค่าเน็ตก้อนใหญ่

### เลือกเทมเพลต

พอกดจะเช่า ระบบจะถามว่าอยากให้ลงอะไรมาให้ **เลือกอันที่ชื่อมีคำว่า ComfyUI**

เทมเพลตคือชุดซอฟต์แวร์สำเร็จรูปที่ติดมากับเครื่อง ถ้าเลือกอันที่ไม่มี ComfyUI
คุณจะได้เครื่องเปล่าที่ต้องลงเองทั้งหมด ซึ่งคู่มือชุดนี้ไม่ครอบคลุม

ถ้ามีหลายอันที่ชื่อมี ComfyUI ให้เลือกอันที่ดูเป็นทางการที่สุดหรือมีคนใช้เยอะที่สุด
อันไหนก็ได้ ตัวติดตั้งของเราหาเองได้ว่า ComfyUI ถูกวางไว้ตรงไหน

> **จุดที่คนพลาด** เห็นราคาต่อชั่วโมงถูกแล้วรีบกด แต่ค่าโหลดไฟล์แพง
> พอรวมแล้วจ่ายมากกว่าเครื่องที่ราคาต่อชั่วโมงสูงกว่าเสียอีก **ดูค่าเน็ตด้วยเสมอ**

## ขั้นที่ 3 — เปิดเครื่องแล้วเข้า Jupyter

กด **Rent** แล้วรอสักครู่ เครื่องจะไปโผล่ที่หน้า **Instances**

ตอนแรกสถานะจะขึ้นว่ากำลังโหลดอยู่ (`loading` / `creating`) **รอจนกว่าจะเปลี่ยนเป็นพร้อม**
(`running` / มีปุ่มให้กดเข้าใช้งาน) ปกติใช้เวลา 1–5 นาที ถ้าเกิน 15 นาทีแล้วยังไม่ขยับ
ให้ Destroy แล้วเลือกเครื่องใหม่

ในกล่องของเครื่องจะมีปุ่มอยู่สามแบบ **จำไว้ตั้งแต่ตอนนี้ว่าอันไหนคืออันไหน**:

| ปุ่ม | ทำอะไร | เสียเงินต่อมั้ย |
|---|---|---|
| **Open** / **Jupyter** | เข้าไปใช้งานเครื่อง | — |
| **Stop** | หยุดชั่วคราว ไฟล์ยังอยู่ | **ยังเสีย** ค่าที่เก็บข้อมูล |
| **Destroy** | ลบทิ้งถาวร ไฟล์หายหมด | ไม่เสียแล้ว |

กด **Open** หรือ **Jupyter** จะเปิดแท็บใหม่ขึ้นมา

**Jupyter คืออะไร** — หน้าเว็บที่ให้เราสั่งงานเครื่องที่เช่ามาได้ คล้ายๆ หน้าจอคอมอีกเครื่อง
ที่เปิดผ่านเบราว์เซอร์

## ขั้นที่ 4 — เปิดหน้าต่างพิมพ์คำสั่ง

หน้า Jupyter ที่เปิดมาจะมีตารางไอคอนสี่เหลี่ยมเรียงกันเป็นแถวๆ แบ่งเป็นสองกลุ่ม
**มีหัวข้อกำกับแต่ละกลุ่ม และหัวข้อนั่นแหละคือตัวชี้ขาด**

```
  Notebook                      ← กลุ่มนี้ห้ามกด
  ┌─────────┐  ┌─────────┐
  │Python 3 │  │  ...    │
  └─────────┘  └─────────┘

  Other                         ← กลุ่มนี้แหละ
  ┌─────────┐  ┌─────────┐  ┌─────────┐
  │Terminal │  │ Console │  │  Text   │   ← กดอันที่เขียนว่า Terminal
  └─────────┘  └─────────┘  └─────────┘
```

**สิ่งที่ต้องมองหา: คำว่า `Terminal` ที่อยู่ใต้หัวข้อ `Other`**
ไอคอนของมันมักเป็นสี่เหลี่ยมพื้นดำ

> **ห้ามกดอันที่อยู่ใต้หัวข้อ `Notebook` เด็ดขาด** โดยเฉพาะอันที่เขียนว่า `Python 3`
> คำสั่งที่เราจะใช้เป็นคำสั่งของระบบ ไม่ใช่ภาษา Python
> **นี่คือจุดที่คนพลาดมากที่สุดในคู่มือทั้งชุด**
>
> **รู้ได้ยังไงว่ากดผิด** — ถ้าได้หน้าที่มีช่องสี่เหลี่ยมว่างๆ ให้พิมพ์ทีละช่อง
> และมีคำว่า `[ ]` อยู่ข้างซ้าย นั่นคือ Notebook กดผิดแล้ว
> ปิดแท็บนั้นทิ้งแล้วกลับมาเลือกใหม่
>
> ถ้าเผลอพิมพ์คำสั่งลงไปแล้ว จะขึ้นตัวหนังสือสีแดงว่า `SyntaxError` — ไม่มีอะไรเสียหาย
> แค่กดผิดที่ ปิดทิ้งแล้วเริ่มใหม่ได้เลย

กดแล้วจะได้จอสีดำที่มีตัวอักษรกะพริบอยู่ — ถูกแล้ว จากนี้ไปคือที่ที่เราจะวางคำสั่ง

**วิธีวางคำสั่ง** คลิกในจอดำหนึ่งครั้ง แล้วกด `Ctrl+V` (บน Mac ใช้ `Cmd+V`) แล้วกด `Enter`

## เวลาจะเลิกใช้

**อย่าลืมกดปิดเครื่อง** ที่หน้า Instances (ปุ่ม Destroy) ไม่งั้นจะโดนคิดเงินต่อไปเรื่อยๆ
แม้จะปิดเบราว์เซอร์ไปแล้ว

- **Stop** = หยุดชั่วคราว ยังเสียค่าที่เก็บข้อมูลอยู่ แต่ไฟล์ยังอยู่
- **Destroy** = ลบทิ้ง ไม่เสียเงินอีก แต่ **ไฟล์ทั้งหมดหายไปด้วย** ต้องโหลดโมเดล 38 GB ใหม่ในครั้งหน้า

โหลดคลิปที่เจนเสร็จลงเครื่องตัวเองให้ครบก่อนกด Destroy เสมอ
